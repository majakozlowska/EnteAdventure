# Ente Adventure 🦆
**Ente Adventure** to gra zręcznościowa stworzona w języku Python z wykorzystaniem biblioteki pygame. Gracz wciela się w postać kaczki, której zadaniem jest unikanie nadlatujących pocisków i zbieranie wzmocnień (powerupów), aby przetrwać jak najdłużej i zdobyć rekordowy wynik. Szczegółowa dokumentacja dostępna jest w pliku `raport.pdf`

## 🎮 Tryby gry
* **Single Player:** Celem jest zdobycie jak najwyższego wyniku punktowego
* **Two Players:** Rywalizacja dwóch graczy. Wygrywa ten, kto przetrwa dłużej

## ⌨️ Sterowanie
* **Gracz 1 (Single Player / Two Players):** Klawisze `W`, `S`, `A`, `D`
* **Gracz 2 (Two Players):** Strzałki

## 🛠️ Technologie i mechanika
**Język:** Python 3

**Biblioteki:** `pygame`, `random`, `sys`

**Główne elementy:**
* System kolizji
* Dynamicznie generowane przeszkody o losowej prędkości i położeniu
* Wizualizacja punktów życia oraz wyniku w czasie rzeczywistym

## 🚀 Szybki start
1. Upewnij się, że masz zainstalowanego Pythona oraz bibliotekę pygame.
2. Rozpakuj archiwum projektu.
3. Uruchom plik główny:
```bash
python game_ente.py

```
